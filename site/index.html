Attention is all you've got.

Spend it on what needs you. Inbox sorts code reviews, your agents' questions and the mail that matters by your rules and your own agent, down to one short list.

Try the demo

Install

On macOS and Linux, one command installs the app, signs you in with the GitHub CLI and sets up your agent.

curl -fsSL https://useinbox.dev/install | bash

It runs install.sh from the repository. Run it again to update.

Runs on your machine
Inbox reads GitHub as you, through the GitHub CLI. Your list, rules and notes stay on your computer.
Uses your agent
AI reviews and answers come from your own Claude Code, Codex or OpenCode, signed in as you.
Writes when you say so
Inbox changes GitHub only when you press a button that says so. Hand off a PR and your agent may fix CI, reply and merge it, or hand it back.
