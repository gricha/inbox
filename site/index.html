Install

One command on macOS and Linux. It installs the app, signs you in with the GitHub CLI, and sets your agent up if one runs it.

curl -fsSL https://useinbox.dev/install | bash

Runs install.sh from the repository. Run it again to update. On Windows, download it from Releases.

Writes only on your click

Inbox writes to GitHub only when you press a button that says so, and logs each write.
